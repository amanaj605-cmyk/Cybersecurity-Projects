# Log Analyzer & SIEM Project

## Overview

This project demonstrates basic Security Information and Event Management (SIEM) concepts using Python.

The project analyzes log files, detects failed login attempts, monitors logs in real time, and generates security alerts.

## Features

* Log Analysis
* Failed Login Detection
* Real-Time Log Monitoring
* Brute Force Attack Detection
* Alert Generation
* Security Report Creation

## Files

* `log_analyzer_v1.py` – Basic log analyzer
* `real_time_monitor.py` – Real-time log monitoring
* `real_time_siem.py` – SIEM event detection
* `real_time_siem_v2.py` – Advanced SIEM with brute-force alerts
* `siem_report_generator.py` – Generates security reports

## Example Detection

LOGIN_FAILED user=admin

After multiple failed attempts:

WARNING: admin has 3 failed attempts!
