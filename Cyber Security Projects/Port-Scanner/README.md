# Port Scanner

A Python-based cybersecurity project that scans a target host for open TCP ports.

## Features

* Scans a user-defined port range
* Detects open ports
* Displays total open ports found
* Measures scan duration
* Uses Python socket programming

## Technologies Used

* Python
* socket
* time

## How to Run

```bash
python port_scanner.py
```

Enter:

* Target IP address or domain
* Start port
* End port

## Example

Target:
scanme.nmap.org

Port Range:
1 - 1000

Sample Result:
Port 22 is OPEN
Port 80 is OPEN

## Learning Outcomes

This project demonstrates:

* TCP port scanning
* Socket programming
* Network reconnaissance basics
* Python automation
